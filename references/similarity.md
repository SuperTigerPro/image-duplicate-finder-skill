# 整图相似检测：只调一个门槛

本页说明普通 `similar` 整图算法。使用 CopyNCE 检查局部复用请转至 [模型查重](copynce.md)。它只列出候选，不删除、移动或修改原图，不调用外部模型或网站。

## 用户只需要一个调节参数

~~~bash
.venv/bin/python scripts/find_duplicates.py "/用户选定的图片目录" \
  --mode similar --similarity-threshold 90 --output-dir "./reports/similar-新名称"
~~~

- 参数为 --similarity-threshold，允许 **0～100 的整数**。
- **默认推荐90**，通常不用调整；日常建议 **80～95**。
- 想少漏一些可调到80或85；想减少误报可调到95。
- 越高越严格，越低越宽松；不提供 pHash、dHash、SSIM、颜色权重等用户调参项。
- 100 沿用原始分辨率的严格像素核验；不是“缩略图看起来一样”。文件内嵌备注不同但像素一致，可以得到100；文件字节相同请用 exact。
- 低于80会提示误报、计算量和结果量可能增加。0代表在支持的静态范围内接纳所有成功处理的图片对，不是推荐的查找设置。

**分数不是相同像素百分比，也不是“来自同一张图”的概率。** 除严格像素核验通过的100分，其余结果都只称为“疑似相似”，必须人工复核。

## 环境与范围

Python 3.10+；在同一个虚拟环境中安装 [相似检测依赖](../requirements-similar.txt)：

~~~bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-similar.txt
~~~

Windows 使用 .venv\Scripts\python.exe 替代 .venv/bin/python。原有 exact 仍只依赖标准库；pixels 仍只需 Pillow。

首版支持 Pillow 可解码的普通 8 位、调色板、1位/灰度/RGB/RGBA **静态单帧图**。动画、多页 TIFF、CMYK/整数/浮点等特殊模式、可能降低精度的高位深图、多分辨率 ICO、损坏或缺少解码器的图片会记录错误，返回1并保留其他可用结果，不会用第一帧或有损转换冒充完整检测。

主要用于同图缩放、格式变化、重新压缩和轻微亮度/颜色变化。不承诺裁剪、局部复用、拼接、任意角度旋转、翻转或语义相似；降低门槛不会自动切换到这些能力。EXIF 标记的显示方向会被正常校正。

## 自动判定流程

1. 只扫描用户选定的路径，沿用隐藏项、递归和符号链接规则。
2. 通过既有安全读取器校验文件状态；使用 EXIF 校正方向。
3. 计算完整解码像素指纹供100分核验。该指纹包含原始解码尺寸、规范化像素及 ICC 配置，不依赖缩略图。
4. 等比缩放到128×128比较画布，白色补边，不强行拉伸或裁剪。透明图按统一白底显示，同时单独保留透明度特征，不因转灰度而丢掉颜色/透明度差异。
5. 计算64位 pHash、64位 dHash、亮度 SSIM、16×16空间颜色/透明度及宽高比特征。
6. 用 Hamming 距离 BK-tree 索引筛选 pHash 候选；100门槛直接按严格像素指纹查找。候选筛选不会故意丢弃本算法中达到门槛的图片对。
7. 先执行廉价的自动门槛，再对仍有可能通过的候选计算 SSIM。评分定义固定，门槛只用于筛选和提前排除不可能通过的候选。
8. 按图片对输出，不做相似关系传递合并。A像B、B像C，不会凭此新增A与C的结果。
9. 输出前再次检查结果中涉及的文件是否变化；变化的相关图片对会移除并记录错误。

## 评分定义（技术说明，无需用户配置）

算法标识为 static-similarity-min-v1。为了避免某个很高的指标掩盖其他明显差异，使用多个已归一化分数的**保守最小值**，而不是不断随门槛改变权重。

设 p / d 是 pHash / dHash 不同的位数：

- pHash分数 = 100 − 100×p/64。
- dHash分数 = max(0, 100 − 100×d/80)。
- 结构分数 = clamp(200×SSIM − 100, 0, 100)。SSIM在128×128亮度图上使用7×7均匀窗口、样本协方差、L=1、K1=0.01、K2=0.03。
- 颜色/透明度分数 = 100×(1 − 归一化绝对差均值)，使用16×16空间特征。
- 宽高比分数 = 100×(较小宽高比 / 较大宽高比)²。
- ICC 配置不同不做隐式色彩管理，综合分数上限保守设为89.9，并附警告。

完整像素指纹相同直接记100。其余候选取上述分数及99.9上限的最小值；展示时向下保留1位小数，不四舍五入冒充100或跨越整数门槛。

门槛T自动推导候选门槛。例如 T=90 时，pHash最多差6位、dHash最多差8位、SSIM至少0.95；颜色、透明度和宽高比门槛同时自动收紧。这些内部值记录在 JSON 中供审计，**不是需要用户选择的参数**。

同一文件和同一软件/解码器版本下，评分不会因T变化。**在完整扫描中**，提高T只会保持或减少结果，降低T只会保持或增加结果。达到安全上限或发生读取错误的结果不完整，不能用部分结果比较全目录召回情况。

## 输出与复核

沿用新报告目录中的文件名，便于 Agent / 工具适配器使用：

- duplicates.json：schema_version=2，使用 similar_pairs；旧的 groups 为空，不把疑似相似误称为重复组。
- duplicates.csv：每个图片对一行，含分数、门槛、严格像素一致标记、两个完整路径和硬链接信息。
- duplicates.md：逐对完整路径、分数、警告和错误；不据此计算可释放磁盘空间。
- similarity-preview.png：有结果时自动生成前12对的本地并排预览，左/右与清单顺序一致。预览有数量上限不代表完整清单被截断。

低纹理、纯色或大面积空白图会附加人工复核提示；即使高分，也不能证明同源。报告和预览可能含敏感路径或图像内容，不经用户许可不能公开或上传。

完整数据结构见 [报告格式](report-format.md)。

## 资源与完整性

为避免低门槛导致无界的两两比较，内部安全上限为：最多处理10,000个成功提取特征的图片，最多200,000个候选图片对，最多20,000个匹配图片对；预览最多12对。它们不是普通用户调参项。

达到处理/候选/匹配上限会明确记录 SimilarityLimitError、complete=false、退出码1，不会静默截断后声称扫描完整。可提高相似度门槛或分目录扫描；原图始终保持只读。0门槛的计算量可能接近两两枚举，禁止将其描述为对任意大图库都能快速完成。

同一图片的完整像素和比较特征使用受状态检查的独立读取，以兼容解码器关闭输入流的行为。它不是文件系统事务快照，请暂停图库同步或编辑后扫描。
